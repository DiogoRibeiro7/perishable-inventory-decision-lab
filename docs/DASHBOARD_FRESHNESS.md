# Dashboard Freshness Expectations

| Signal | Expected freshness | Use before outcome arrives |
| --- | ---: | --- |
| Feature snapshot | 6h | Yes |
| Recommendation batch | 6h | Yes |
| Publication status | 15m | Yes |
| Pipeline completeness | 15m | Yes |
| Incident status | 15m | Yes |
| Sales outcomes | 48h | No final judgement until complete |
| Waste outcomes | 48h | No final judgement until complete |
| Override reasons | 6h | Yes |
| Supplier exceptions | 24h | Yes |

Dashboards must visually separate leading indicators from outcomes that arrive later. Late outcomes should show a completeness banner and sample size rather than a final status.
