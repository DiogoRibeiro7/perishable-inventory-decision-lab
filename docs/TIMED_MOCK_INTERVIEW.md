# Timed Mock Interview Script

## Thirty-Minute Version

```text
00:00-03:00  Candidate gives project overview.
03:00-08:00  Forecasting: quantiles, pinball loss, calibration, conditional coverage.
08:00-13:00  Decision layer: lead-time aggregation, critical fractile, constraints.
13:00-18:00  Simulator: event order, conservation, validation, limitations.
18:00-22:00  Production: batch publication, rollback, monitoring, security.
22:00-26:00  Challenge mode: invalid quantile addition, false promotion causal claims, no-overlap evaluation.
26:00-30:00  Store operations: overrides, discovery, first 90 days.
```

## Sixty-Minute Version

```text
00:00-05:00  Project narrative and assumptions.
05:00-15:00  Probabilistic forecasting and calibration derivations.
15:00-25:00  Inventory theory and simulator whiteboard.
25:00-35:00  Offline evaluation, experiments, and rollout.
35:00-45:00  Architecture, dbt, GCP, Airflow, publication, and CI.
45:00-52:00  Monitoring, incidents, rollback, security, and cost.
52:00-58:00  Product judgement and store-operator communication.
58:00-60:00  Candidate states limitations and next validation steps.
```

## Panel Instructions

Use the challenge questions when an answer sounds memorized or overconfident. Award more credit for naming assumptions and failure modes than for claiming certainty.
