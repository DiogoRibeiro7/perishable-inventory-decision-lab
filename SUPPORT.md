# Support

This repository is maintained as a public portfolio and reproducible software project.

## Questions

Use the GitHub question issue form for:

- Installation or demo run questions.
- Forecast or policy interpretation.
- Metrics and release artifact questions.

## Bugs

Use the GitHub bug report form when package behavior is broken or inconsistent with documented behavior. Include the command, seed, input shape, and shortest useful output.

## Security

Do not use public issues for security-sensitive reports. Follow [`SECURITY.md`](SECURITY.md).
